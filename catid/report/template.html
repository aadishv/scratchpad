      Notes for Claude

      How each variant scores

      Cross-visit top-1: for each labeled crop, is the most similar crop from a different visit the same cat? Same-visit matches are excluded, since burst shots make them trivial.
      Set top-1 / top-3: all crops of one cat from one visit, matched as a group against other visits. Top-3 is the "is it one of these three?" prompt.
      End-to-end acc: replay visits in date order. Cluster each visit's crops, match each cluster to cats confirmed on earlier visits (with a recency prior), or call it a new cat. A crop is right if it gets its true cat, or "new" when that cat was never seen before. Known cat right is the same, counting only cats seen before and ignoring the new-cat threshold.
      Within-visit F1: B-cubed F1 of clustering one visit's crops by cat (best threshold).
      Open-set: replaying visits in order, does a query get the right known cat, or "new cat" if it has never been seen?
